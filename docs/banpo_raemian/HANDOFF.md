# 인수인계 — 반포 래미안 실거래가 수집 (로컬 세션 이어받기용)

작성 2026-08-20. 클라우드 세션에서 준비한 내용을 로컬에서 이어서 실행하기 위한 문서.

## 0. 결론 3줄

1. 코드는 **완성·검증까지 끝났고** 이 브랜치에 있습니다. 남은 건 **로컬에서 실행 한 번**뿐입니다.
2. 클라우드 세션에서는 조직 egress 정책이 `apis.data.go.kr` 을 차단해 **수집을 못 했습니다**(우회 시도 안 함).
3. 로컬에는 그 제약이 없으므로, 인증키만 넣고 스크립트를 돌리면 전량 수집 + 평형별 정리가 끝납니다.

## 1. 지금 바로 할 일

```bash
git clone https://github.com/dreamerstar88-ui/market-dashboard.git
cd market-dashboard
git checkout claude/banpo-lamian-transaction-data-rjc2kf

# 인증키 (공공데이터포털 > 마이페이지 > 개발계정 > 일반 인증키 Decoding)
export MOLIT_SERVICE_KEY='발급받은_인증키'          # Windows PowerShell: $env:MOLIT_SERVICE_KEY='...'

# (권장) 먼저 오프라인 테스트로 환경 확인 — 네트워크 없이 도는지 봅니다
python scripts/test_molit_rtms_offline.py
python scripts/test_firstige_offline.py

# 목표 작업: 래미안퍼스티지 전량 수집 + 매매/전세/월세 × 평형별 정리
python scripts/firstige_report.py --start 200901 --outdir data/firstige
```

약 400회 API 호출(매매 212개월 + 전월세 188개월)이라 몇 분 걸립니다.
중간에 끊겨도 월별 원본 XML이 `data/firstige/_cache/` 에 남아 재실행 시 재호출하지 않습니다.

## 2. 파일 구성

| 파일 | 역할 |
|---|---|
| `services/molit_rtms_service.py` | 국토부 오픈API 클라이언트. 3개 엔드포인트, 페이징, totalCount 검증, 지수 백오프 재시도, 월별 XML 캐시, 영문→한글 필드 매핑 |
| `scripts/firstige_report.py` | **주 작업물.** 래미안퍼스티지 전용 수집 + 평형별 정리 |
| `scripts/collect_banpo_raemian.py` | 반포·잠원 래미안 7개 단지 전체 수집 (범위 확대용) |
| `scripts/test_firstige_offline.py` | 리포트 파이프라인 오프라인 검증 (19항목) |
| `scripts/test_molit_rtms_offline.py` | 수집기 오프라인 검증 (12항목) |
| `docs/banpo_raemian/README.md` | 가능성 분석, 단지 목록, 분양 정보, API 사양 |
| `docs/banpo_raemian/snapshot_recent12m.md` | 최근 12개월 참고 스냅샷 (카카오 부동산 경유, 부분 자료) |

두 테스트 모두 **현재 전체 통과** 상태입니다.

## 3. `firstige_report.py` 산출물

대상: 서울 서초구 반포동 18-1 래미안퍼스티지 (2009-07 입주, 2,444세대)

정리 축 두 가지:
- **축 1 — 거래유형**: 매매 / 전세 / 월세 (전월세 API 결과를 월세금액 0 여부로 분리)
- **축 2 — 평형**: 전용면적 ÷ 3.3058 로 평 환산해 묶고, 전용면적별 상세도 유지

| 산출 파일 | 내용 |
|---|---|
| `firstige_매매_전건.csv` / `_전세_` / `_월세_` | 전건 원본 + 파생컬럼(평형, 평수, 평당_만원, ㎡당_만원, 등기일자) |
| `firstige_평형별_매매.csv` / `_전세` / `_월세` | 평형별 건수·평균·중위·최저·최고, 최초/최근 계약일, 등기일자 보유 건수 |
| `firstige_평형별연도별_매매.csv` / `_전세` / `_월세` | 평형 × 연도 평균가 피벗 |
| `REPORT_firstige.md` | 위 6개 표를 담은 리포트 |

- 해제(취소) 거래는 **모든 집계에서 제외**하고 건수만 따로 표기합니다.
- 단지명은 공백 제거 후 부분일치로 매칭합니다("래미안 퍼스티지" 표기도 잡힘).

## 4. 반드시 알고 있어야 할 데이터 제약

| 항목 | 내용 |
|---|---|
| 매매 공개 범위 | **2006년 1월 계약분부터** |
| **등기일자** | **2023년 1월 1일 계약분부터만** 공개. 그 이전은 공란 — "등기까지 확인된 거래"로 한정하면 퍼스티지는 2023년부터만 가능 |
| 최초 분양가 | 실거래가 자료에 **없음** (청약홈 입주자모집공고 소관) |
| 분양권/입주권 | 별도 API로 수집 가능 (`--kinds 분양권`) |
| 전월세 | 2011년경부터 공개 |
| 동·호 | 개인정보 보호로 비공개(층만 공개) |
| 신고 지연 | 계약일 기준 30일 이내 신고 → 최근 1~2개월분은 계속 늘어남. 주기적 재실행 필요 |

## 5. 클라우드 세션에서 확인/수정된 것

- **단지 목록 오류를 바로잡았습니다.** 처음 5개로 봤으나 실제 반포·잠원 래미안은 **7개**입니다.
  누락됐던 것: `반포래미안아이파크`(반포동 1341, 829세대, 2018-08), `반포래미안트리니원`(반포동 1109,
  2091세대, 2026-08 입주). 수집기 필터는 `래미안` 부분일치라 코드는 이미 두 단지를 커버하고 있었습니다.
- 잠원동 래미안은 신반포팰리스·신반포리오센트 2곳이 전부임을 확인했습니다.
- 트리니원은 미입주라 거래가 **입주권/분양권**으로 잡힙니다 → 범위를 넓힐 때 `분양권` 포함 필수.
- 분양가(별도 조사): 원베일리 3.3㎡당 5,653만원(2021-06) / 원펜타스 6,736만원(2024-07) /
  트리니원 8,484만원(2025-11). 원베일리 분양가를 한국 CPI로 2025년 가치 환산 시 약 6,431만원.

## 6. 미해결 / 판단 필요

- **MCP 서버**: `https://mcp-creator.playmcp-endpoint.kakaocloud.io/s/generated-server-4f7782/mcp`
  MCP-Creator DSL이 반복문·조건문·응답 필터링을 지원하지 않아 **전량 수집 용도로는 부적합**합니다.
  단발 조회용으로만 유효하며, 클라우드에서 호출이 막혀 **동작 검증을 못 했습니다**.
  생성 시 인증키를 서버에 내장했으므로, 쓰지 않을 거면 대시보드에서 삭제 권장.
- **인증키 재발급 권장**: 대화에 평문 노출 + MCP 서버 내장. 저장소에는 커밋되지 않았음(검사 완료).
- 범위를 7개 단지 전체로 넓히려면 `scripts/collect_banpo_raemian.py` 를 쓰면 됩니다.
- 2023년 이전 등기 확인이 꼭 필요하면 대법원 인터넷등기소 건별 유료 열람 외에는 방법이 없습니다.
