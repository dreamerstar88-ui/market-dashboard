# 반포·잠원 래미안 실거래가 전량 수집

## 1. 결론: 어디까지 가능한가

| 항목 | 가능 여부 | 근거 |
|---|---|---|
| 단지별 아파트 **매매 실거래가** 전량 | ✅ **2006년 1월 계약분부터** | 국토부 실거래가 공개 대상이 2006년 1월 신고분부터 |
| **등기일자(소유권이전등기 신고일)** 포함 | ⚠️ **2023년 1월 1일 계약분부터만** | 국토부가 대법원 등기정보와 연계해 공개 시작. 그 이전 계약분은 등기 정보 자체가 비공개 |
| **분양 시점**의 최초 분양가 | ❌ 실거래가 자료에 없음 | 분양가는 청약홈 입주자모집공고 소관. 실거래가 시스템은 '거래'만 공개 |
| 분양 직후 **분양권/입주권 전매** 거래 | ✅ 별도 자료로 수집 가능 | 아파트 분양권전매 실거래가 자료 |
| 전월세 | ✅ (2011년~) | 아파트 전월세 실거래가 자료 |
| **해제(취소) 거래** 식별 | ✅ | `해제여부`/`해제사유발생일` 항목 |

즉 **"분양시기부터 최근까지 한 건도 빠짐없이"는 매매 기준으로 가능**하지만,
**"등기부 신고까지 확인된 건"으로 한정하면 2023년 1월 이후 계약분에서만 가능**합니다.
2009년 입주한 래미안퍼스티지의 2009~2022년 거래는 국토부가 등기일자를 공개하지 않으므로
등기 확인 여부를 알 수 없습니다(거래 자체는 전부 수집됩니다).

단지별 등기일자 확보 가능 구간:

| 단지 | 법정동 | 입주 | 매매 수집 가능 | 등기일자 확보 가능 |
|---|---|---|---|---|
| 래미안퍼스티지 | 반포동 | 2009-07 | 2006-01~ | 2023-01 계약분~ |
| 래미안신반포팰리스 | 잠원동 | 2016-06 | 2006-01~ | 2023-01 계약분~ |
| 래미안신반포리오센트 | 잠원동 | 2019-06 | 2006-01~ | 2023-01 계약분~ |
| 래미안원베일리 | 반포동 | 2023-08 | 2006-01~ | **전 기간** (입주가 2023-08) |
| 래미안원펜타스 | 반포동 | 2024-08 | 2006-01~ | **전 기간** |

## 2. 데이터 출처

공공데이터포털(data.go.kr) 국토교통부 오픈API 3종:

| 거래구분 | 엔드포인트 |
|---|---|
| 매매(상세, 등기일자 포함) | `https://apis.data.go.kr/1613000/RTMSDataSvcAptTradeDev/getRTMSDataSvcAptTradeDev` |
| 전월세 | `https://apis.data.go.kr/1613000/RTMSDataSvcAptRent/getRTMSDataSvcAptRent` |
| 분양권·입주권 전매 | `https://apis.data.go.kr/1613000/RTMSDataSvcSilvTrade/getRTMSDataSvcSilvTrade` |

요청 파라미터: `serviceKey`, `LAWD_CD`(시군구 5자리), `DEAL_YMD`(YYYYMM), `pageNo`, `numOfRows`.
API는 **단지 단위 조회를 지원하지 않으므로**, 서초구(`11650`) 전체를 월 단위로 훑은 뒤
법정동(반포동·잠원동) + 단지명 `래미안` 부분일치로 거릅니다.
단지명 화이트리스트가 아니라 부분일치를 쓰는 이유는 표기 흔들림("래미안 원베일리" vs "래미안원베일리")과
과거 표기 변경으로 인한 누락을 막기 위해서입니다.

## 3. 실행 방법

```bash
# 1) 공공데이터포털에서 위 3개 API '활용신청' (승인 즉시~2시간)
#    마이페이지 > 개발계정 > 일반 인증키(Decoding) 복사
export MOLIT_SERVICE_KEY='발급받은_일반인증키_Decoding'

# 2) 전 구간 수집 (2006-01 ~ 이번 달)
python scripts/collect_banpo_raemian.py --start 200601 --outdir data/banpo_raemian

# 매매만, 특정 구간만
python scripts/collect_banpo_raemian.py --kinds 매매 --start 202301 --end 202608

# 서초구 전체 래미안(에스티지·서초에스티지S 등 포함)
python scripts/collect_banpo_raemian.py --all-seocho-raemian
```

산출물 (`--outdir`, 기본 `data/banpo_raemian/`):

- `banpo_raemian_all.csv` — 전체 통합 (UTF-8 BOM, 엑셀 바로 열림)
- `banpo_raemian_매매.csv` / `_분양권.csv` / `_전월세.csv`
- `banpo_raemian.sqlite` — `transactions` 테이블
- `REPORT.md` — 단지별 건수·최초/최근 계약일·등기일자 보유 건수·해제 건수, 연도별 매매 건수
- `_cache/{거래구분}/{시군구}/{YYYYMM}_p1.xml` — 월별 원본 XML (감사·재현용, 재실행 시 재호출 안 함)

## 4. 누락 방지 장치

- 월별 `totalCount`와 실제 수집 건수를 대조하고, 불일치 시 경고 + 종료코드 1
- 페이지 끝까지 순회 (`numOfRows=1000` 기준 페이징)
- 네트워크 오류는 지수 백오프로 최대 5회 재시도
- 거래 식별 키(단지·지번·면적·층·계약일·금액)로 중복 제거 — 재실행해도 중복 누적 없음
- 원본 XML 캐시 보존 → 파싱 로직을 바꿔도 재호출 없이 재생성 가능

## 6. 알려진 제약

- 국토부 실거래가는 **계약일 기준 30일 이내 신고**이므로 최근 1~2개월분은 계속 늘어납니다. 주기적 재실행 필요.
- 아파트 매매는 개인정보 보호로 **동·호는 비공개**(층만 공개). 등기 완료 건에 한해 일부 정보가 추가 공개됩니다.
- 해제(취소)된 거래도 응답에 남아 있습니다. 시세 분석 시 `해제여부`가 `O`인 건은 제외하세요.
- 2006년 이전 거래, 그리고 최초 분양 계약(분양가) 자체는 이 자료로 확보할 수 없습니다.
